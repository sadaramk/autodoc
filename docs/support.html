What it reads

Languages, frameworks and formats

Support is per-signal rather than per-language: a repository in an unlisted language still gets containers, deployment topology and evidence from its manifests and Dockerfiles — it just gets no API contracts or flows.

Known gaps

  • Authentication applied by middleware, rather than per route, is not attributed to the operations it protects.
  • A port with several implementations is left unresolved rather than guessed. Which one a service uses is often decided by dependency-injection wiring at startup, which is not in the source — so a request flow through such a port stops at the port.
  • A call into a library the service links is not followed, so work a shared package does on the service's behalf does not appear as a step in its flows.

The rules behind each of these — how units, compose services, calls, datastores and events are recognised, and where each stops — are written out in HEURISTICS.md.

Something missing or wrong for your stack is worth an issue — the templates are built around exactly those two cases.
